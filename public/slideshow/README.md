# پوشه تصاویر اسلایدشوی صفحه اصلی // Home Hero Slideshow

شما می‌توانید تصاویر دلخواه خود را برای اسلایدشوی بالای صفحه اصلی (Hero Section) در این پوشه قرار دهید.

### فرمت‌های پیشنهادی:
- `slide-1.jpg` یا `slide-1.webp` (تصویر اسلاید اول)
- `slide-2.jpg` یا `slide-2.webp` (تصویر اسلاید دوم)
- `slide-3.jpg` یا `slide-3.webp` (تصویر اسلاید سوم)
- `slide-4.jpg` یا `slide-4.webp` (تصویر اسلاید چهارم)

### نکات بهینه‌سازی:
- **نسبت تصویر پیشنهادی:** ۱۶:۹ یا ۴:۳ با رزولوشن افقی ۱۲۰۰ تا ۱۹۲۰ پیکسل (مثلاً ۱۹۲۰x۱۰۸۰ یا ۱۲۰۰x۸۰۰).
- **حجم فایل:** ترجیحاً کمتر از ۱ مگابایت برای لود فوق‌سریع.
- اگر فایلی اضافه کردید، کامپوننت اسلایدشو به طور پیش‌فرض مسیرهای `/slideshow/slide-1.jpg` الی `/slideshow/slide-4.jpg` را می‌خواند. اگر نام‌های متفاوتی انتخاب کردید، می‌توانید لیست آرایه را در `src/components/home/HeroSlideshow.tsx` تنظیم نمایید.

---

### English:
Place your homepage hero slideshow images here.
Supported default filenames:
- `slide-1.jpg`
- `slide-2.jpg`
- `slide-3.jpg`
- `slide-4.jpg`

Recommended resolution: 1200px - 1920px wide (16:9 or 4:3 aspect ratio).
